# BINRAT

> He gets the scraps. You get the receipts.

**BINRAT / `$BINRAT`** is an autonomous Arc launch-intelligence project built around one stupidly simple metaphor: new launches are hot garbage, and a cyber-rat digs through the dumpster looking for scraps of useful evidence.

The useful part is factual launch intelligence: chain-bound launch identity, creator/deployer history, time-bound observations, and replayable receipts.

The token is **not launched in V0**. This repository has no signing, trading, private-key, BUY/SELL recommendation, or capital-execution authority.

## Locked product language

- New-launch feed: **HOT GARBAGE**
- Investigation: **DIGGING**
- Creator history: **TRASH TRAIL**
- Evidence artifact: **RECEIPT**
- Primary line: **He gets the scraps. You get the receipts.**
