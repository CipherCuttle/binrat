## Shared production rules

- Master vectors use outlined paths plus clean fills; texture is supplied as optional overlay layers so small exports remain readable.
- Raster masters are authored at 2× delivery size. Preserve generous transparent safe areas around asymmetrical objects.
- Small marks must pass at 16 px in one color. Product objects may use the full palette but cannot depend on color for semantic state.
- Evidence states always retain text in UI. Artwork may reinforce `COMPLETE`, `PARTIAL`, `UNVERIFIED`, or `MISSING`; it never replaces those words.
- The approved mascot establishes anatomy, black fur, damaged/digital eye, lighting, and attitude. Any derived state must match that subject rather than invent a second rat.

## Rive state machine

One `BinratFieldUnit` state machine should expose:

- boolean inputs: `indexing`, `hasEvidence`, `hasRecurrence`, `isEmpty`, `hasError`, `receiptVerified`, `reducedMotion`;
- trigger inputs: `dig`, `found`, `compare`, `verify`, `reset`;
- numeric inputs: `recurrenceCount` clamped 0–8 and `evidenceMaturity` clamped 0–3;
- text alternatives supplied by the host UI for `idle`, `indexing`, `digging`, `evidence_found`, `repeat_creator`, `empty`, `error`, and `receipt_verified`;
- deterministic priority: error → empty → repeat creator → evidence found → digging/indexing → idle;
- no timer-generated success, recurrence, verification, or empty state. Inputs come only from validated product state;
- reduced-motion mode removes loops and spatial movement, retaining a single-frame pose plus eye/state change;
- artboards: `hero_landscape` 16:9, `panel_portrait` 4:5, `compact_square` 1:1. Keep the mascot registration point consistent so swaps do not jump.
