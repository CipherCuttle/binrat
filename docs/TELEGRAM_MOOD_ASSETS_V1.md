# BINRAT Telegram mood assets V1

These eleven 480 × 480 PNGs derive from the owner-supplied approved pixel-art BINRAT rat, downsampled to a 96 × 96 pixel grid and enlarged 5× with nearest-neighbor. The **character master remains** `web/assets/binrat-character-master.png` and is not replaced.

The Cloudflare static asset directory is `web`. Public media URLs are `/assets/telegram/<state>.png` on the same verified HTTPS Worker origin. The profile asset is prepared here, but setting @BinratBot's Telegram profile picture requires explicit BotFather or authorized Telegram profile configuration; committing the PNG does **not** change the avatar.

States: idle-neutral, cheeky, inquisitive, digging, evidence-found, repeat-creator, alert, empty-paws, error, insulted, profile. Do not derive factual evidence, creator identity, recommended trades, or verified status from a picture. Actual textual/receipt content remains authoritative. The insult gesture is a deterministic addressed banter reaction, not a judgment about token or creator evidence.
