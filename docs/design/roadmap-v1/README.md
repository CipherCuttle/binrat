## Raster-only rule

Anything that physically exists inside the BINRAT world must come from authored raster artwork.

Allowed browser work:

- layout;
- black edge falloff;
- opacity / brightness;
- transforms;
- central roadmap spine / node UI;
- raster layer choreography.

Forbidden pictorial substitutes:

- SVG scene illustrations;
- Canvas scene illustrations;
- CSS-drawn rooms, terminals, pipes, radar hardware, filing cabinets, paper or rats;
- procedural DOM scene illustrations.

The current branch has an automated scene-purity gate for these regressions.
