# BINRAT G1a — three complete hybrid visual concepts

**Exploration, not an approved style guide.** Source `G1A_FIXTURE.json` v2 applies byte-for-byte to all three; no visual direction has been selected. Each uses the owner-supplied artwork UNALTERED: the rat is a dominant character only on Fresh Garbage, a small supporting presence on investigation. Historic receipt and fictional DEMO scenario are different labeled cases. Screens below specify hierarchy, interactions and mobile behavior without selecting permanent color palette, font or shape rules.

## A. Dumpster Workshop — an expressive HQ and a serious workbench

**Whole-world hypothesis.** The user visits the rat's real dumpster headquarters. There is evidence in the trash, not a decorative dashboard pretending to be a game. Main home hero uses the supplied image as a source-preserving full artwork panel, plus a clear detached *factual* reading panel. Background props can be lively; token facts and focus/CTA remain ordinary legible interface layers. During investigation, the artwork contracts to a quiet corner identification tile, as if the investigator pulled a folder from the dumpster workbench.

**Home / five-second hierarchy.** (1) Heading `Fresh Pons V2 launches`, (2) a highly legible visible `Verified historical receipt` for token `0xb0ee…563d9` with `25 Sep 18:40 UTC`, `ETH pair`, `funding / price unknown`, (3) a single primary `Investigate this launch` action plus secondary `View receipt`. Illustration frames, but never overlays, these facts. First-screen noise is capped at the character, one lead finding and at most two smaller verified receipt markers. The art deliberately extends beyond a conventional banner, but not over the CTA or text.

**Dossier / thirty-second route.** User opens a physical-looking workbench case with a crisp content column: title `0xb0ee…563d9 · Verified launch`, first-party verified event fact row, curve address, originalDeployer role and timestamp; dedicated source receipt action; a plainly prominent `Funding not investigated / pricing not reconstructed` box. An optional `Preview an example Rat Trap — DEMO` moves to a different fictional case with persistent conspicuous banner. The real panel never inherits the demo funding relationship. A breadcrumb and Discover control remain near the title.

**Rat Trap and Watch route.** The `MOLD (DEMO)` case has a simple chronological transfer-trail rail showing four hypothetical transfers from `DEMO-FUNDER-A`: 0.18 ETH to MOLD (current), 0.11 to GRIME (9d old), 0.14 to SLUDGE (5d old) and 0.07 to DUST (1d old). Each is an illustrative transfer to a different DEMO launch address, never an inferred common human owner. A fold-out small funding diagram is *disabled in the first view* because a linear list explains four fictional funded launches without giant bubbles. The three *previous* demo launches (distinct from current MOLD) show GRIME 48k→7.2k est. FDV / SLUDGE 31.5k→12.5k / DUST immature price unknown. They now each have a corresponding hypothetical DEMO-FUNDER-A funding record. Selector 6h/24h/3d/7d always shows the exact denominator: 3 previous launches total; age eligible 3/3 at 6h and 24h, 2/3 at 3d, 1/3 at 7d; price-supported among those 2/3, 2/3, 2/2 and 1/1, respectively. DUST is age-eligible for 6h/24h but price-UNKNOWN, and immature for 3d/7d; SLUDGE is immature for 7d. Only GRIME qualifies by age and simulated coverage for a 7d display. Scalar synthetic peaks are NOT per-window price series. Separate panels show demo funding activity, synthetic estimated FDV and **exit liquidity UNKNOWN**. Primary CTA `Preview a watch for DEMO-FUNDER-A`; inspect channel, target, event and unmeasured delivery; `Save preview locally` visibly confirms no real monitoring.

**Signature interaction.** Rat performs a pixel-faithful, skippable rummage gesture *after* the user chooses to scan, then reveals an evidence slip whose factual summary is already screen-reader accessible. A sound cue is opt-in only. Unconventional choice: the home navigation looks like tool labels on the dumpster edge, but each label has ordinary semantic text and focused outlines; acceptance requires first-visit users to find Investigate without needing to explore decoration.

**Responsive / a11y.** Desktop: image and factual panel side by side, workbench content in a narrower center column. 320/360px: the lead finding/CTA comes BEFORE or alongside the image in DOM and painted order; art remains sizable but cannot consume the entire first viewport. 390/430px: slightly more image and a secondary receipt card. Dossier becomes a single vertical column; chronological rail becomes an accessible ordered list; charts are opt-in. Test visible focus, no touch targets smaller than accessible benchmark without justification, reduced-motion static rat, long address wrapping/copy, source error and unknown funding. **Failure to watch:** a beautiful scene that reads as a game, delays proof or forces the user to hunt for a button.

**Art / typography exploration, nonbinding.** Physical painted rust, city-night graffiti and worn workshop surfaces are source inspiration from the supplied art; keep information surfaces visually calm. Do not infer that purple, neon, CRT scanlines, specific web fonts or bento grids are accepted. Use only limited atmospheric motion, never perpetual chart/card shimmer.

## B. Underground Intelligence Bureau — a rat-run investigative desk

**Whole-world hypothesis.** Underground municipal records office meets illicit street-level intelligence bureau. The expressive rat operates the home desk as a slightly mischievous dispatcher, while source-backed findings use exact documentary semantics rather than fictional spy confidence. Investigation is a disciplined high-clarity case desk. The visual idea is **official-looking paperwork with visibly unofficial character**, not another grid of trading terminal widgets.

**Home / five-second hierarchy.** A compact dispatch ticker conveys only source status and time. The largest visual item is one `Pons V2 launch verified` dispatch with token `0xb0ee…563d9`, ETH pair, historic timestamp and `Funding / price unknown`; `Open dossier` is the only dominant action. Original rat artwork anchors a separate bureau-wall panel, roughly equal visual prominence to the featured dispatch but never interrupting screen-reader or DOM reading order. Two other narrow source receipts can be viewed after the primary dispatch but never claim discovered funders.

**Dossier / thirty-second route.** Clicking the dispatch opens a tagged case with a strong top proof band: chain, source classification `factory event observed`, tx hash and block 72448839; structured originalDeployer role versus unknown fee recipient. Information is grouped by `What we can prove`, `What we have not checked`, `Source receipts`, `Optional historical research`, then `Preview a DEMO`. The title, meaningful fact and next action stay visible without scrolling past decorative art. The rat is now a small desk-stamp-sized witness, not a competing hero.

**Rat Trap and Watch route.** Switching into MOLD's separate DEMO dossier uses a documentary file: left to right on desktop, an observed-time DEMO funding table, three *previous*, separately funded fictional launch file rows (GRIME, SLUDGE, DUST), explanatory status for price-UNKNOWN, immature DUST, and clearly separated metric panes. 6h/24h/3d/7d selectors adjust declared windows, not fabricated real charts. Funding addresses are roles, not identities. `Preview watch` opens a drawer with exact demo target/event/channel; control confirms `Preview saved locally; live alerts not enabled`. On mobile the drawer is a full-screen sheet with standard close/back affordance and focus restoration.

**Signature interaction.** As the user opens a source receipt, a physical-feeling date-and-source stamp appears **only** if receipt exists. Its accessible text says exactly which source, block and event was established. Missing price gets an explicit blank field `Not reconstructed` rather than an empty placeholder. Unconventional choice: an evidence availability margin runs persistently beside the case; acceptance requires that compact status remain readable and not duplicate the main content or degrade at 320px.

**Responsive / a11y.** At desktop, a narrow dispatch rail / substantial reading plane / small optional source sidebar; no massive quant dashboard. At 320/360 all rails collapse: featured finding, dossier title, proof, unknowns, CTA, receipts, optional demo in that order. At 390/430 a few secondary dispatch lines can appear after proof. Hide nonessential decorative desk scene at narrow widths when necessary, but keep rat personality in one restrained tile. Keyboard shortcuts are a later enhancement; navigation never depends on them. Test focus moving into/out of Watch sheet, stale-source status distinct from no launches, unit labels and 7d partial cohort.

**Art / typography exploration, nonbinding.** Competing typography might juxtapose utilitarian evidence text against cheeky handmade rat interventions, while avoiding unreadable tiny monospaced data. Inspiration is physical archive lighting and ink on rough paper, not a forced monochrome, green phosphor or fixed grid. **Failure to watch:** an attractive but generic Bloomberg imitation or oppressive false-authority aesthetic, especially if users interpret the stamp as source truth beyond its actual receipt.

## C. Living Case File — receipts become a navigable story

**Whole-world hypothesis.** Each launch accumulates a living evidence dossier. The experience emphasizes chronological discovery and how proofs connect through time; documents and marginal notes are functional navigation, not arbitrary scrapbooking. The rat dominates the landing archive room, then retreats to occasional tiny evidence annotations, as if he found the original file and let the user do the analysis.

**Home / five-second hierarchy.** An open lead folder in the middle of the page carries `Verified Pons V2 launch`, `0xb0ee…563d9`, ETH pair, exact source observation time, `Funding & price not verified` and `Read this case`. The provided original artwork is a distinct, prominent panel alongside the archive, not recreated pixel-by-pixel by any generator. Home previews two additional verified case tabs with no unsupported outcomes. A subtle source-ribbon indicates these are *historical receipts*, not live feed cards.

**Dossier / thirty-second route.** The first open page is a one-screen `What happened` summary, with direct timeline `factory event → token + curve created → current verification limit`, block/tx provenance and distinction between originalDeployer and fee recipient UNKNOWN. The opposing page is `What we don't know` with funding/curve/V4/pricing unknown states and actionable source or coverage explanations. `Show receipt` expands the primary source in place, rather than navigating away; `Preview a fictional linked case — DEMO` leads to a separately branded fictional file. All links remain ordinary accessible controls despite document-like appearance.

**Rat Trap and Watch route.** A DEMO funding timeline is the **spine** of the file. Evidence strips link DEMO-FUNDER-A's four fictional transfers to MOLD/GRIME/SLUDGE/DUST, explicitly explaining `same transfer source does not prove same owner`. Three dated *prior*-launch leaflets show GRIME / SLUDGE / DUST and precise simulated coverage; all three have their own explicit fictional transfer receipt in the frozen fixture, while current MOLD is the fourth recipient. The 6h/24h/3d/7d windows distinguish the three-row funder cohort from the 2/3, 2/3, 2/2 and 1/1 price-supported/age-eligible observations, with immature DUST and 7d-immature SLUDGE retained as visible missing cases. 6h/24h/3d/7d selection is tabular by default with optional miniature graphs if source coverage suffices (DEMO only). Users can unfold one simple relationship diagram after seeing the chronological facts; no default bubble constellation. Watch preview is a bookmark in the folder, but the CTA and eventual confirmation plainly say `Preview`, not `Monitoring active`.

**Signature interaction.** Clicking a verified receipt visually and semantically opens its corresponding source fragment and preserves a deep link to the same source. Unconventional choice: a narrow vertical fold / page spine conveys causal chronology across screens; acceptance requires that an expert can jump directly to source or Watch without repeating every page-turn gesture. In reduced motion, page changes are instant with persistent breadcrumbs.

**Responsive / a11y.** Desktop uses an asymmetrical two-page composition only when text measure stays readable; there is no decorative literal binding down the middle obstructing selection/copy. Mobile 320/360/390/430 uses one page in normal vertical reading order (summary → facts → unknowns → source → DEMO switch), persistent Back and optional jump controls. The rat illustration moves after the lead finding when space is scarce. Price charts, receipts and long address strings get scrolling *within purpose-built panels*, never a page-wide overflow. Test keyboard-operated source open/close, anchor restoration, screen-reader timeline, stale-source badge text and no overclaim from decorative document 'stamps'. **Failure to watch:** the file metaphor becomes obligatory animation or requires three taps to access basic facts.

**Art / typography exploration, nonbinding.** Photocopied source fragments, margin scratches and pasted slips can feel like the dumpster world's natural evidence trail; final visual materials, type and palette remain owner-unselected. No permanent scrapbook CSS rule just because a discovery page succeeds.
